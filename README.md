AIRPG is a platform for creating and playing TTRPG

The goal is to provide a structured, extensible environment for:

Creating game elements like worlds (settings), items, spells, classes, creatures, maps, game systems etc.

Game-mode with AI GM, automatic long-term memory and self-expending settings, image, items, enemys, quest generation and a lot more.

Modular system for the export and import of user-created game elements and systems available via Steam workshop or files.

First priority is implementing DnD system.

⚠️ The project is in an early stage of development, architecture and infrastructure are prioritized over feature implementation. I don't have too much time to work on this, so progress can be slow.
